Importante para pedidos reales

Esta versión guarda pedidos en LocalStorage: la vista de cocina solo comparte pedidos con el mismo navegador/dispositivo. Para que el celular del cliente envíe pedidos a otra pantalla de cocina en tiempo real, necesitas conectar una base de datos y un backend (por ejemplo, Supabase).
